# Mobeen Nasir — Portfolio

Personal portfolio website of **Mobeen Nasir**, BS Biotechnology student at Bahauddin Zakariya University, Multan. Built as a narrative résumé for international master's scholarship applications.

**Live site:** https://mobeennasir.github.io/portfolio/

## Contents

- `index.html` — the complete portfolio site. Fully self-contained: markup, styles, and scripts are inline, and the profile photo is embedded, so this single file is the entire website.
- `mobeen-nasir-cv.pdf` — Europass CV, linked from the site's Download CV button.

## Updating

- **Site content:** edit `index.html` directly. No build step; open it in a browser to preview.
- **CV:** replace `mobeen-nasir-cv.pdf`. Keep the same filename, or update the button link in `index.html` to match the new name.
- **Photo:** the portrait is embedded in `index.html`; replace the embedded image to change it.
